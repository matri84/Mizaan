## معرفی

**میزان** یک برنامه‌ی تحت وب برای مدیریت لیست خرید است. اقلام را با نام، مقدار و واحد اضافه می‌کنید، هر وقت خواستید ویرایش یا حذف می‌کنید و در پایان یک فایل PDF مرتب و آماده‌ی چاپ می‌گیرید تا موقع خرید کنار هر قلم تیک بزنید.

برنامه فقط با HTML، CSS و جاوااسکریپت ساده نوشته شده است. نیازی به سرور، بک‌اند یا ساخت (build) ندارد.

## امکانات

- افزودن، ویرایش و حذف اقلام خرید
- واحدهای آماده: عدد، لیتر، کیلوگرم، گرم، بسته، شانه، جعبه و سبد
- پذیرش عدد اعشاری و اعداد فارسی (مثلاً `۳.۴` یا `3.4`)
- اعتبارسنجی فرم همراه با پیام خطای واضح
- ذخیره‌ی خودکار لیست در مرورگر (`localStorage`) و ماندن اطلاعات بعد از رفرش
- ساخت PDF با:
  - هدر شامل لوگو، تاریخ شمسی و تعداد اقلام
  - کادر تیک کنار هر قلم برای استفاده‌ی چاپی
  - جلوگیری از بریده شدن اقلام بین دو صفحه
  - شماره‌ی صفحه در پایین هر برگ
- رابط راست‌به‌چپ (RTL) و ریسپانسیو برای موبایل و دسکتاپ
- escape شدن ورودی کاربر برای جلوگیری از به‌هم‌ریختن HTML

## تکنولوژی‌ها

| کاربرد | ابزار |

## اجرا

پروژه نیاز به نصب هیچ پکیجی ندارد.

```bash
git clone https://github.com/<username>/<repo>.git
cd <repo>
```

سپس فایل `index.html` را در مرورگر باز کنید. اگر دوست دارید با یک سرور محلی اجرا کنید:

```bash
# با Python
python -m http.server 8000

# یا با Node.js
npx serve .
```

و آدرس `http://localhost:8000` را باز کنید.

## نحوه‌ی استفاده

1. نام محصول، مقدار و واحد را وارد کنید و روی **افزودن** بزنید.
2. برای تغییر یک قلم، روی آیکن مداد بزنید، مقدار را اصلاح کنید و **ذخیره‌ی تغییرات** را بزنید.
3. برای حذف یک قلم از آیکن سطل زباله و برای خالی کردن کل لیست از **پاک کردن همه** استفاده کنید.
4. با دکمه‌ی **ساخت فایل لیست خرید**، فایل `mizaan-report.pdf` دانلود می‌شود.

### نکته درباره‌ی وارد کردن اعداد

| ورودی | نتیجه |
|---|---|
| `3.4` | ۳٫۴ |
| `۳.۴` | ۳٫۴ |
| `3٫4` | ۳٫۴ |
| `3/4` | ۳٫۴ (اسلش به ممیز تبدیل می‌شود، نه کسر) |
| `1,000` | ۱۰۰۰ (کاما جداکننده‌ی هزارگان است) |

## محدودیت‌های شناخته‌شده

- فونت پیش‌فرض jsPDF فارسی را پشتیبانی نمی‌کند، به همین دلیل شماره‌ی صفحه در PDF با اعداد انگلیسی نوشته می‌شود.
- `html2pdf.js` کل گزارش را به‌صورت تصویر رندر می‌کند. برای لیست‌های بسیار بلند (چند صد قلم) ممکن است به محدودیت اندازه‌ی canvas مرورگر برخورد کند.
- اطلاعات فقط روی همان مرورگر و همان دستگاه ذخیره می‌شود و بین دستگاه‌ها همگام نمی‌شود.
